# Генератор Промптов для Рассказов

Веб-приложение на Python для создания детализированных промптов для написания рассказов. Система позволяет управлять категориями, персонажами, локациями и другими параметрами, а затем генерировать случайные промпты на основе этих данных.

## Возможности

- **Управление категориями** - создание главных категорий рассказов (Романтика, Приключения, Драма и т.д.)
- **Подкатегории** - детализированные сюжетные линии с настройками персонажей
- **Характеристики персонажей** - гибкая система типов характеристик (внешность, темперамент и т.д.) с фильтрацией по полу
- **Локации** - управление странами, типами местности и конкретными местами
- **Тоны и стили** - настройка тонов повествования и стилей диалогов
- **Генерация промптов** - автоматическая генерация текстовых промптов на русском языке

## Структура системы

1. **Категории** - общее направление рассказа
2. **Подкатегории** - конкретный сюжет, который определяет:
   - Количество персонажей (мин/макс)
   - Спецификации каждого персонажа (пол, возраст, может ли иметь инициативу)
   - Разрешенные перспективы повествования
3. **Персонажи** - генерируются автоматически:
   - Инициатива - чья воля движет события
   - Отношение - для персонажей без инициативы (от негативного до позитивного)
   - Характеристики - случайные значения из базы
4. **Место действия** - случайная комбинация страны, типа местности и конкретного места
5. **Тон и стиль** - определяют атмосферу рассказа

## Установка

### Требования

- Python 3.8+
- pip

### Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

При первом запуске автоматически создается база данных SQLite с примерами данных.

## Использование

### Веб-интерфейс

1. Откройте браузер и перейдите на `http://localhost:5000`
2. Используйте навигационное меню для управления данными:
   - **Категории** - добавление/удаление категорий
   - **Подкатегории** - создание подкатегорий с настройками персонажей
   - **Характеристики** - управление типами характеристик и их значениями
   - **Локации** - добавление стран, типов местности и конкретных мест
   - **Тоны** - настройка тонов повествования
   - **Стили диалогов** - управление стилями диалогов
3. Перейдите на страницу **Генерировать** и нажмите кнопку "Сгенерировать промпт"
4. Скопируйте полученный промпт для использования в вашем творческом процессе

### API Endpoints

Система предоставляет RESTful API для программного управления:

#### Категории
- `GET /api/categories` - получить все категории
- `POST /api/categories` - создать категорию
- `GET /api/categories/<id>` - получить категорию
- `PUT /api/categories/<id>` - обновить категорию
- `DELETE /api/categories/<id>` - удалить категорию

#### Подкатегории
- `GET /api/subcategories` - получить все подкатегории
- `POST /api/subcategories` - создать подкатегорию
- `GET /api/subcategories/<id>` - получить подкатегорию
- `PUT /api/subcategories/<id>` - обновить подкатегорию
- `DELETE /api/subcategories/<id>` - удалить подкатегорию

#### Типы характеристик
- `GET /api/character-trait-types` - получить все типы
- `POST /api/character-trait-types` - создать тип
- `PUT /api/character-trait-types/<id>` - обновить тип
- `DELETE /api/character-trait-types/<id>` - удалить тип

#### Значения характеристик
- `POST /api/character-trait-values` - добавить значение
- `DELETE /api/character-trait-values/<id>` - удалить значение

#### Локации
- `GET /api/countries` - получить все страны
- `POST /api/countries` - добавить страну
- `DELETE /api/countries/<id>` - удалить страну

- `GET /api/location-types` - получить все типы местности
- `POST /api/location-types` - добавить тип
- `DELETE /api/location-types/<id>` - удалить тип

- `GET /api/locations` - получить все места
- `POST /api/locations` - добавить место
- `PUT /api/locations/<id>` - обновить место
- `DELETE /api/locations/<id>` - удалить место

#### Тоны
- `GET /api/tones` - получить все тоны
- `POST /api/tones` - добавить тон
- `PUT /api/tones/<id>` - обновить тон
- `DELETE /api/tones/<id>` - удалить тон

#### Стили диалогов
- `GET /api/dialogue-styles` - получить все стили
- `POST /api/dialogue-styles` - добавить стиль
- `PUT /api/dialogue-styles/<id>` - обновить стиль
- `DELETE /api/dialogue-styles/<id>` - удалить стиль

#### Генерация промпта
- `POST /api/generate-prompt` - сгенерировать промпт

Пример:
```bash
curl -X POST http://localhost:5000/api/generate-prompt -H "Content-Type: application/json"
```

## База данных

Приложение использует SQLite для хранения данных. База создается автоматически при первом запуске.

### Таблицы:
- `categories` - категории рассказов
- `subcategories` - подкатегории с настройками персонажей
- `character_trait_types` - типы характеристик персонажей
- `character_trait_values` - возможные значения характеристик
- `countries` - страны
- `location_types` - типы местности
- `locations` - конкретные места
- `tones` - тоны повествования
- `dialogue_styles` - стили диалогов

## Разработка

Приложение написано на Flask с использованием:
- **Flask** - веб-фреймворк
- **SQLAlchemy** - ORM для работы с базой данных
- **Vanilla JavaScript** - для фронтенда (без дополнительных фреймворков)
